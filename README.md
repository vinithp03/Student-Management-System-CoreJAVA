# Student Management System

This is a simple console-based Student Management System built using Core Java. It allows users to add, get, and remove student details such as name, roll number, age, and gender. The system ensures that the roll number is unique and that valid data is entered for age and other details.

## Features

- **Add Student Details:** Allows users to add student details (name, roll number, age, and gender).
- **View Student Details:** Displays all added student details.
- **Remove Student Details:** Allows users to remove a student’s data using their roll number.
- **Data Validation:** Ensures that the roll number is unique and age is within a valid range (18-100).

## Prerequisites

- Java (JDK) version 8 or above
- A text editor or IDE (Eclipse, IntelliJ IDEA, etc.) for running Java code.

## How to Run

1. Clone or download this repository.
2. Open the project in your preferred IDE or text editor.
3. Compile and run the `Main.java` file.
4. Follow the on-screen instructions to interact with the application.

## Usage

1. Upon running, the user will be prompted to enter an option:
   - `add`: To add a new student's details.
   - `get`: To view all stored student details.
   - `remove`: To remove a student’s details based on their roll number.

2. After performing an operation, you can choose to add/delete/show more details or exit the application by typing `yes` or `no`.
